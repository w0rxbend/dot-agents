# Browser-source rendering and lifecycle

Portfolio evidence: [overlay socket lifecycle](https://github.com/w0rxbend/twitch-vizer/blob/7fa2861b322a75f9ad5fb395e616645d7f063ab5/frontend/src/shared/socket.ts), [wire normalization](https://github.com/w0rxbend/twitch-vizer/blob/7fa2861b322a75f9ad5fb395e616645d7f063ab5/frontend/src/shared/events.ts), [CreationEngine](https://github.com/w0rxbend/obs-effects/blob/ad8d6fd8767c7bd90a9746b076c80797cf53c46d/src/engine/engine.ts) and [CameraScreen](https://github.com/w0rxbend/obs-effects/blob/ad8d6fd8767c7bd90a9746b076c80797cf53c46d/src/app/screens/CameraScreen.ts). obs-effects is archived; use it as existing-code context, not an instruction to revive it. General Pixi API guidance belongs in the version-matching [PixiJS docs](https://pixijs.com/8.x/guides/components/application).

Preserve a transparent canvas and browser-source dimensions. Pixi 8 initialization is asynchronous: do not use a renderer/canvas or attach scene assets before `init` and the required bundle load complete. Derive resolution from the existing helper and renderer limits; blindly raising device-pixel ratio increases texture and render-target cost. Keep effect animation proportional to elapsed time rather than a presumed fixed refresh rate.

Treat initialization, active display, hidden/paused state, reconnection, scene replacement and destruction as different lifecycle states. Socket ownership guards must cover late open, message, close and retry callbacks. The reviewed socket guards an old close but not every callback; stale open/message callbacks can still change status or inject old events after replacement. Teardown should cancel retry timers, detach listeners/ticker callbacks, close sockets, dispose scene-owned textures/filters/media and abort pending work. Shared asset-cache textures need explicit ownership; destroying one scene must not break another. Pause/resume rules should respect OBS source behavior and audio expectations.

Keep event normalization in the shared boundary: camelCase/snake_case avatar and animated/static emote aliases are tolerated there, not independently by every card renderer. Supply fallback assets/text for malformed or unavailable external media. Bound cards/particles, GPU caches and animated-image decoders so a long-running source does not grow with every user/message.

Use HTTPS→WSS URL derivation and the existing deployment proxy/path; do not hard-code a development port into a production scene. Preserve `?debug=1` gating for synthetic key-triggered events. Validate resize, asset readiness, transparency, disconnect/reconnect, hidden/resumed state and repeated scene teardown. Record browser/WebGL checks separately from actual OBS embedded-browser checks; an ordinary Chromium test does not prove identical OBS CEF behavior.
