# CAD artifacts and native reopening

Match the locked build123d version; Tigerbeetle V2 targets the 0.11 series. Consult its [versioned import/export documentation](https://build123d.readthedocs.io/en/v0.11.0/import_export.html) for units and export options. STEP geometry, STL tessellation and native document structure require different checks. Preserve component names/placement and expected solid counts through assembly exports. Mesh deflection and angular tolerance affect curved geometry and artifact size; do not equate a nonempty STL with a correct boundary representation.

The [FreeCAD adapter](https://github.com/w0rxbend/FreeCAD-Projects/blob/826231b01444c893c95c819e9e759f4b6f520b4d/Tigerbeetle%20V2/src/fpv_frame/export/freecad.py) runs a separate FreeCADCmd Python runtime. Its worker intentionally does not import build123d or fpv_frame. Preserve executable discovery, configured FREECAD_CMD semantics, subprocess timeout/diagnostics and offscreen operation. A Flatpak runtime needs explicit document-path and environment access; installing a Python FreeCAD-looking package into uv does not supply this native runtime.

The [worker](https://github.com/w0rxbend/FreeCAD-Projects/blob/826231b01444c893c95c819e9e759f4b6f520b4d/Tigerbeetle%20V2/src/fpv_frame/export/freecad_worker.py) imports canonical STEP, recomputes and checks shapes, saves FCStd, closes it, opens it again, recomputes and reinspects. Count physical leaves once rather than counting their assembly compounds twice. Compare component identity and solid count exactly, volumes with the stated relative/absolute tolerance. FreeCAD's [Document API](https://freecad.github.io/SourceDoc/d8/d3e/classApp_1_1Document.html) documents the native document boundary; use runtime-matching APIs.

Require the passed reopen report before promoting an output from its temporary directory. Keep the companion report and artifact manifest consistent; replacing a model and a report separately is not a multi-file atomic transaction. A ZIP-shaped FCStd or successful subprocess exit alone is insufficient.

[Native tests](https://github.com/w0rxbend/FreeCAD-Projects/blob/826231b01444c893c95c819e9e759f4b6f520b4d/Tigerbeetle%20V2/tests/exports/test_freecad.py) are gated by FPV_TEST_FREECAD=1. They cover named assemblies and real curved frame components; boxes alone missed floating mass-property drift. The [CAD workflow](https://github.com/w0rxbend/FreeCAD-Projects/blob/826231b01444c893c95c819e9e759f4b6f520b4d/.github/workflows/tigerbeetle-v2-cad.yml) uses checksum-pinned FreeCAD1.1.3, native tests, all presets, drawings and release inventory. Record skipped native tests explicitly instead of treating ordinary pytest success as save/reopen coverage. Do not regenerate unrelated committed outputs or publish release artifacts merely to inspect a change.
