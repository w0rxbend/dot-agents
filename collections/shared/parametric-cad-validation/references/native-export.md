# CAD artifacts and native reopening

Match locked build123d version; Tigerbeetle V2 targets 0.11 series. Check its [versioned import/export documentation](https://build123d.readthedocs.io/en/v0.11.0/import_export.html) for units and export options. STEP geometry, STL tessellation and native document structure need different checks. Keep component names/placement and expected solid counts through assembly exports. Mesh deflection and angular tolerance affect curved geometry and artifact size. Nonempty STL does not mean correct boundary representation.

[FreeCAD adapter](https://github.com/w0rxbend/FreeCAD-Projects/blob/826231b01444c893c95c819e9e759f4b6f520b4d/Tigerbeetle%20V2/src/fpv_frame/export/freecad.py) runs separate FreeCADCmd Python runtime. Its worker deliberately does not import build123d or fpv_frame. Keep executable discovery, configured FREECAD_CMD semantics, subprocess timeout/diagnostics and offscreen operation. Flatpak runtime needs explicit document-path and environment access. Installing FreeCAD-looking Python package into uv does not supply this native runtime.

[Worker](https://github.com/w0rxbend/FreeCAD-Projects/blob/826231b01444c893c95c819e9e759f4b6f520b4d/Tigerbeetle%20V2/src/fpv_frame/export/freecad_worker.py) imports canonical STEP, recomputes and checks shapes, saves FCStd, closes, reopens, recomputes and reinspects. Count each physical leaf once; do not double-count via assembly compounds. Compare component identity and solid count exactly; compare volumes within stated relative/absolute tolerance. FreeCAD's [Document API](https://freecad.github.io/SourceDoc/d8/d3e/classApp_1_1Document.html) documents native document boundary; use runtime-matching APIs.

Promote output from its temporary directory only after reopen report passes. Keep companion report and artifact manifest consistent. Replacing model and report separately is not atomic across files. ZIP-shaped FCStd or successful subprocess exit alone is not enough.

[Native tests](https://github.com/w0rxbend/FreeCAD-Projects/blob/826231b01444c893c95c819e9e759f4b6f520b4d/Tigerbeetle%20V2/tests/exports/test_freecad.py) are gated by FPV_TEST_FREECAD=1. They cover named assemblies and real curved frame components; boxes alone missed floating mass-property drift. [CAD workflow](https://github.com/w0rxbend/FreeCAD-Projects/blob/826231b01444c893c95c819e9e759f4b6f520b4d/.github/workflows/tigerbeetle-v2-cad.yml) uses checksum-pinned FreeCAD1.1.3, native tests, all presets, drawings and release inventory. Record skipped native tests explicitly; ordinary pytest success is not save/reopen coverage. Do not regenerate unrelated committed outputs or publish release artifacts merely to inspect change.
