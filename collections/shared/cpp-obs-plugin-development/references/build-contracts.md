# Fork and build compatibility

Reviewed [obs-aitum-multistream CMake root](https://github.com/w0rxbend/obs-aitum-multistream/blob/c48b4bf182f8b354255df7329c9afe3dee4f9820/CMakeLists.txt) checks whether CMAKE_PROJECT_NAME is obs-studio. Out-of-tree builds find libobs and obs-frontend-api and link OBS::obs-frontend-api. In-tree builds link OBS::frontend-api. Both link libobs. Preserve this distinction rather than renaming targets until one local configure passes.

MODULE plugin with Qt6 Core/Widgets, CURL, AUTOMOC/AUTOUIC/AUTORCC and resources.qrc. On named Unix platforms, Qt below6.9 adds GuiPrivate. That private API is a concrete dependency constraint: do not upgrade Qt or remove the dependency without inspecting consumers. Keep QObject headers/resource files in build inputs, generated version metadata and plugin output name/install helper consistent. Windows CRT setting and macOS deployment target affect artifact compatibility.

[buildspec.json](https://github.com/w0rxbend/obs-aitum-multistream/blob/c48b4bf182f8b354255df7329c9afe3dee4f9820/buildspec.json) selects OBS31.0.0-fix1 from a specific fork and hashed OBS/Qt/prebuilt bundles. “Latest OBS docs” does not authorize raising that baseline. Recheck current checkout before changing dependencies. Validate each supported matrix member; do not claim Windows/macOS portability from a Linux build.

Use matching [configure/build presets](https://github.com/w0rxbend/obs-aitum-multistream/blob/c48b4bf182f8b354255df7329c9afe3dee4f9820/CMakePresets.json) and [workflow actions](https://github.com/w0rxbend/obs-aitum-multistream/blob/c48b4bf182f8b354255df7329c9afe3dee4f9820/.github/workflows/build-project.yaml). Presets inherit OBS dependency-build options. Their ENABLE_QT/FRONTEND_API=false values do not mean plugin stopped using Qt/frontend APIs. Inspect context before toggling. Reviewed [format workflow](https://github.com/w0rxbend/obs-aitum-multistream/blob/c48b4bf182f8b354255df7329c9afe3dee4f9820/.github/workflows/check-format.yaml) disables jobs with if:false. Workflow filenames alone do not prove enforced lint coverage.

For releases, inspect actual module/resources/locale placement and linked runtime dependencies. Build, packaging, signing and notarization are separate workflow decisions. Compiled module is not a loaded plugin or signed installer. Smoke-test with isolated OBS profile and local/non-broadcast output. Publish fork release only on separate request.
