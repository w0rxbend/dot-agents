# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for this topic. Draw explainer knowledge from here, not from parametric guesses. Wisdom comes from communities listed here.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ by Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for: anything to do with periodisation, recovery, intensity zones.
- [Article: "How Much Should I Train?" by Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for: weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for: programme critique, plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for: real-time coaching feedback on lifts.
```

## Rules

- **High-trust only.** Prefer primary sources, recognised experts, peer-reviewed work, strongly moderated communities. If a resource is marketing dressed as education, leave it out.
- **Annotate every entry.** Add one line: what it covers, when to reach for it.
- **Group by Knowledge / Wisdom.** Mirrors philosophy in [SKILL.md](./SKILL.md). Fine for a resource to appear in only one group.
- **Surface gaps explicitly.** If no good resource exists for an area the mission needs, write a `## Gaps` section listing what is missing. Drives future search.
- **Prune ruthlessly.** Remove resources that proved wrong, shallow, or off-mission; do not bury them. Five sharp sources beat thirty mediocre ones.
- **Record community preferences.** If user opted out of joining communities, note it here so future sessions don't keep proposing them.
