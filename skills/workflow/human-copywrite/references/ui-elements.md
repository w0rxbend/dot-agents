# UI Elements

## Entries

### Action button
Note capitalization.

> Choose a function for the Action button.

### action sheet
iOS and iPadOS: alert shown in response to a control or action, offering two or more choices for current context.

In user materials, don't use *action sheet*, *sheet*, or *popover*; describe what user must select or do.

> Correct: Tap New Tab.
> Incorrect: Tap New Tab in the sheet that appears.

In developer materials, *action sheet* is OK.

See also [popover](#popover); [share sheet](#share-sheet); [sheet](#sheet).

### Action pop-up menu
Pop-up menu labeled with ellipsis and down arrow, in the Finder and some Mac apps.

See also [More button](#more-button).

### alert (n., adj.)
Generic visual (dialog) or auditory (beep) signal calling user's attention to an unusual situation. Visual alerts report error conditions or warn of potentially hazardous situations or actions.

In user materials, use *alert sound* or *alert message* for generic alerts. Avoid *error message* except in developer materials.

> The computer plays a sound (called the *alert sound*) when it needs your attention.
> An alert message appears if a problem occurs during the installation.

In specific situations, avoid the word *alert* when you can describe what happens.

> A message appears when the installation is finished.

### arrow
In user materials, use *pointer* generally. Use *arrow* or *arrow pointer* when comparing pointer types to describe this type.

> When you click the Text tool, the pointer becomes an I-beam.
> Click the Selection tool to display the arrow pointer.

*Cursor* (as in *the VoiceOver cursor*) may fit other interfaces and developer materials.

See also [cursor](#cursor); [insertion point](#insertion-point); [pointer](#pointer).

### arrow keys
Lowercase in general references. Don't use *direction keys*.

When naming a specific arrow key, capitalize and use its complete name.

> Correct: Use the arrow keys to move the insertion point from cell to cell.
> Incorrect: Use the Arrow keys to move the insertion point from cell to cell.
> Correct: Use the Up Arrow and Down Arrow keys to scroll through the document.
> Incorrect: Use the Up and Down Arrow keys to scroll through the document.
> Correct: Press the Left Arrow key.
> Incorrect: Press the Left arrow key.

### Back button
Use for button (usually in toolbar or navigation bar) that returns users to previous screen or webpage.

See also [left arrow](#left-arrow).

### badge (n.)
Small icon, or small graphic with text, overlaid on an app or toolbar icon, file thumbnail, or other UI element to show item info at a glance.

Use *badge* for any of these:

- *A counter:* Usually red oval with a numeral counting active or available items in an app (for example, new email or text messages), available updates, and so on.
- *An indicator of an item's type or state:* For example, in Photos, a badge can show a photo is a Live Photo.
- *A warning:* Exclamation point on an app icon marking an issue needing attention.

Don't use *badge* as a verb or *badged* as an adjective. An item *has* a badge, or a badge *appears* on an item.

### button
Buttons start an action when clicked, tapped, or pressed. You *click* or *tap* an onscreen button.

You *press* a mechanical button.

> Press and hold the TV button.

- *Buttons with text labels:* Write button names exactly as shown onscreen. If name uses sentence-style capitalization, enclose it in quotation marks.

> Click the "Position on screen" button.

If name uses title-style capitalization, don't use quotation marks, even if one word is lowercase.

> Tap Add to Favorites.

If button name is all caps or all lowercase, write it with title-style capitalization.

- *Buttons that display icons or images:* If a UI element acts like a button (starts an action when clicked or tapped), call it a *button*, even if it shows an icon or image.

For some icon buttons, you can name the button by appearance (use lowercase).

*Exception:* Some app icons act like buttons (for example, icons in the macOS Dock or on the iOS Home Screen) but are still called *icons*.

See also [checkbox](#checkbox); [click](voice-and-tone.md#click); [icon](#icon); [More button](#more-button); [radio button](#radio-button); [tab](#tab); [tap (n., v.)](voice-and-tone.md#tap-n-v).

### checkbox
Labeled square control users *select* or *deselect*. Don't tell users to *click* a checkbox: ambiguous, since initial state is unknown.

Saying *checkbox* can help, especially people with visual disabilities.

> Select "Allow repeated calls."
> Select the "Allow repeated calls" checkbox.
> Select the checkbox labeled "Allow repeated calls."

A checkbox is *selected* or *unselected*. Avoid *checked* and *unchecked*.

> If "Allow repeated calls" is unselected, multiple calls from the same person do not go through.
> If "Allow repeated calls" isn't selected, …

See also [radio button](#radio-button); [select (v.)](voice-and-tone.md#select-v).

### close button
macOS: leftmost of three window controls in upper-left corner of title bar.

### color well
Small rectangular or square control for selecting a color.

> When you choose Gradient Fill, two color wells appear below the pop-up menu; select a color from each color well.
> Select the Alternating Row Color checkbox, and then click the color well to select a color.

### Colors window
Systemwide window for selecting colors.

### column view
Way to display and select items in a data hierarchy (for example, the column view in Finder windows).

### Column View button
Button second from right in the View control in Finder windows.

### command
Use *command* or *menu command* in user materials.

> Use the Print command to create a PDF of your document.
> To change the way windows look, use the commands in the View menu.

Use *item* or *option* for menu items that aren't commands, such as font names in a pop-up menu.

A command is *in* a menu, not *on* a menu; a menu *contains* commands. Users *choose* commands; they don't *select* them.

See also [choose](voice-and-tone.md#choose); [command names](capitalization.md#command-names); [menus](#menus).

### connector
Use only for an item that plugs into a receptacle (such as a slot, port, or socket). Terminology:

> *edge connector:* the connector on the edge of a peripheral card; fits into a slot
> *minicircular connector:* an 8-pin connector [Don't use *mini-DIN*.]
> *plug:* a connector with prongs or pins

In user materials, describe connectors by shape and size, by the icon on them, or another way suited to context. Users should identify the connector easily, even without knowing terminology.

Avoid obscure names such as *power input unit*; prefer direct terms such as *plug*. Don't use *male* or *female* for connector types.

See also [jack](#jack); [port](#port); [slot](#slot); [socket](#socket); [USB connector types](abbreviations-and-acronyms.md#usb-connector-types).

### contextual menu
Menu shown when a user presses the Control key and clicks an onscreen item. In user materials, use *shortcut menu*, not *contextual menu*. On first reference, *contextual menu* in parentheses is OK for users who know that term better.

> A shortcut menu (also called a *contextual menu*) appears.

See also [menus](#menus).

### Control Center
Don't precede with *the*.

> Click an item in Control Center to see additional options.

### Control Strip
Set of system controls in the Touch Bar. Items are *in* (not *on*) the Control Strip. You *expand* or *collapse* it (not *show* or *hide* it).

> To change the volume, tap [the speaker icon] in the Control Strip.

See also [Touch Bar](#touch-bar).

### cursor
Don't use for the macOS or iOS interface; use *insertion point* or *pointer*, per context. The term *cursor* fits the VoiceOver interface and may fit other interfaces and developer materials. See also [insertion point](#insertion-point); [pointer](#pointer).

### dialog
In user materials, use *dialog* for windows that request more information from user and are explicitly dismissed by clicking a button in them (for example, OK, Cancel, or Print). Don't use *dialog box*.

Dialogs include alerts, which hold error messages or warnings about potentially hazardous situations or actions. A dialog can be implemented as a sheet attached to a window, but don't use *sheet* in user materials. Examples: Open dialog, Print dialog, Save As dialog, Save Changes alert.

In developer materials, use *panel*, not *dialog*, in most contexts, because dialogs are created with programming symbols such as `NSOpenPanel`. When the developer sees the dialog as a user does (such as in instructions for using developer apps), use *dialog*. Programmatic panels can be windows, not dialogs, in user terminology (for example, the `NSFontPanel` class implements the Fonts window).

See also [alert (n., adj.)](#alert-n-adj); [pane](#pane); [sheet](#sheet); [window](#window).

### disclosure arrow
Button that reveals or hides options when clicked (not the *disclosure button*). Usually no need to say whether it's closed (pointing right) or open (pointing down).

> Correct: You can click the disclosure arrow to reveal more information.
> Avoid: You can click the closed disclosure arrow (pointing to the right) to reveal more information.

In developer materials, this control is a *disclosure triangle*.

See also [disclosure button](#disclosure-button).

### disclosure button
Button with an arrow that expands a dialog or utility window to offer more choices tied to a specific list-based selection control.

Arrow points down when closed. On click, window expands and arrow points up. See also [disclosure arrow](#disclosure-arrow).

### down arrow
Use for small arrow users click to decrease a value in a stepper.

> Click the down arrow to decrease the text indent.

See also [Down Arrow key](#down-arrow-key); [stepper](#stepper).

### drawer
Window that slides out from a parent window when user clicks a button or chooses a command.

### Eject button
Button next to the name of a disk, device, or other item in the sidebar of Finder windows or other app windows. See also [Media Eject key](#media-eject-key).

### field
Use for boxes (in windows and dialogs, for example) where users enter information. No need to specify *text field* or *number field*, but use the field's name if it has one. For example:

> Enter the video timecode in the Current Timecode field.
> Fill in the required fields, and then click Checkout.

For novice users, *text box* or *number box* may fit better; also OK, but stay consistent within a document.

### Forward button
Use for button (usually in toolbar or navigation bar) that moves users forward to next screen or webpage.

See also [right arrow](#right-arrow).

### Gallery View button
In Finder windows, rightmost button in the View control.

Also a Notes app button for showing notes as thumbnails.

### grab point
In iOS, one of a set of movable points around a text selection.

### handle
Use for small control on an object's edge, dragged to move or change the object.

Don't use *drag handle*. In apps with several handle types, you may need to describe or name handles (for example, *white handle*, *outer handle*, *corner handle*, *selection handle*, *fade handle*, *trim handle*).

> Correct: Drag the outer handle away from the center circle.
> Correct: To set the direction of the effect, drag the rotation handle.
> Incorrect: A drag handle appears on the motion path.

See also [grab point](#grab-point).

### Help button
Button that opens Help Viewer. Standard Help button has a question mark graphic.

### help tag
Use for instructional text shown when user holds pointer over an interface element. *Exception:* In content for developers, use *tooltip* instead.

### I-beam
Refers to the I-beam pointer.

### icon
Onscreen graphic representing another item, such as a file in a Finder window or an album in Photos.

- *Icons that don't act like buttons:* If a UI element looks like an icon (graphic without a rectangular border) and doesn't act like a button (doesn't start an action when clicked or tapped), always call it an *icon*.

- *Icons that act like buttons:* If a UI element looks like an icon (graphic without a rectangular border) but acts like a button (causes something to happen when clicked or tapped), call it a *button*.

Can also name it by appearance (use lowercase).

*Exception:* Some app icons act like buttons (for example, icons in the macOS Dock or on the iOS Home Screen) but are still called *icons* (*Click the System Settings icon in the Dock*).

- *Unnamed icons:* If an icon has no label or established name, describe its appearance or function. Use lowercase. If you include an inline graphic of the icon, don't enclose it in parentheses.

See also [button](#button).

### icon view
Way to display and select items as icons (for example, the icon view in Finder windows).

### Icon View button
Leftmost button in the View control in Finder windows.

### insertion point
Use for the point where user types or inserts data.

> The vertical blinking bar marks the insertion point.

See also [cursor](#cursor); [pointer](#pointer).

### inspector
Window for viewing, and often modifying, attributes of a document or selected item. Call it the *inspector* or the *inspector window*.

> You can format most elements of your document using the inspector.
> You can open multiple inspector windows to work with different aspects of your document.

- *Capitalization:* Capitalize *Inspector* in a button name or menu command. Otherwise, lowercase *i*.
- *Panes:* For an inspector pane, use *the [pane name] inspector*.

> Use the Table inspector to change the row height.

- *Inspector buttons:* Multipane inspectors usually have buttons for switching panes. Button name should match the pane it opens.

### jack
Small, round, 1-pin socket for audio and video connections. Don't use *connector* for a jack. See also [connector](#connector); [port](#port); [slot](#slot); [socket](#socket).

### left arrow
Use for button that looks like a left arrow and lets users navigate horizontally through content, such as a category of TV shows in the Apple TV app.

Don't call it the *left arrow button* or the *left-pointing arrow*.

> Click the left arrow to view more episodes.

Don't use when you mean *Back button*.

See also [Back button](#back-button); [Left Arrow key](#left-arrow-key).

See [arrow keys](#arrow-keys).

### list view
Way to display items in a list with one or more data columns (for example, the list view in Finder windows).

### List View button
Button second from left in the View control in Finder windows.

### Media Eject key
Note capitalization.

### menu bar
Bar at top of the Mac screen. Holds menus for the active app (*File menu*, *Edit menu*, and so on) and menus for system status icons (icons on the right, also called *menu bar icons*, *menu bar status icons*, or *menu bar items*). For the menu type, use *pull-down menu*, not *pop-up menu*.

### Menu button
Physical button on the Siri Remote (called the *Apple TV Remote* in countries or regions where Siri isn't available for use with Apple TV) and the Apple Remote.

### menus
Anything choosable in a menu is a *menu item*; some menu items are also *menu commands* (or simply *commands*). A menu item is *in* a menu, not *on* or *under* a menu; a menu *contains* items.

In user materials, *item* or *option* works for menu items that aren't commands, such as font names in a pop-up menu. Prefer a more specific term when possible (for example, for a menu of colors, say *choose a color*).

> To specify how numbers in a spreadsheet are rounded, click the Accuracy pop-up menu, and then choose an option.
> To change the size of icon text, click the "Text size" pop-up menu, and then choose a size.

- *Pull-down menus:* Menus in the menu bar. For choosing an item from one, use this style.

> Choose [menu] > [item] > [submenu item].
> Choose Edit > Find > Find Next.
> Choose File > Save As.

Don't use an angle bracket when only identifying which menu holds the item.

> Correct: the Page Setup command in the File menu
> Incorrect: the File > Page Setup command

Don't call pull-down menus *pop-up menus* or *drop-down menus*. Usually call them *menus*; to distinguish them from other menu types, *pull-down menus* is OK.

- *Pop-up menus:* Menu in a dialog or window, labeled with up and down arrows (or a down arrow alone). Use the style *Click the X pop-up menu, and then choose Y*.

> Click the Connection Speed pop-up menu, and then choose Intranet LAN.
> Click the Format pop-up menu, and then choose a format.

If the pop-up menu has no name, call it *the pop-up menu*.

- *Shortcut menus:* Menu shown when a user presses the Control key and clicks an onscreen item. Use this style.

> Control-click the image, and then choose Copy Image from the shortcut menu.

If shortcut menu has submenus, use the style above or the angle bracket style.

In user materials, don't call a shortcut menu a *contextual menu*, except parenthetically on first reference for users who know that term better.

> A shortcut menu (also called a *contextual menu*) appears.

- *Checkmarks in menus:* For menu items turned on or off by showing or hiding a checkmark, use this language:

> To show the library, choose Window > Library so that a checkmark appears next to Library.
> To hide the library, choose Window > Library so that the checkmark disappears.

See also [choose](voice-and-tone.md#choose); [command names](capitalization.md#command-names); [submenus](#submenus).

### maximize
Use for making a window as big as possible without going full screen. Don't use for clicking a window *minimized* into the Dock; use *make active*.

> Correct: To maximize a window, Option-click the green button.
> Incorrect: To maximize a window, click its icon in the Dock.
> Correct: To make a minimized window active, click its icon in the Dock.

See also [minimize (v.), minimized (adj.)](#minimize-v-minimized-adj).

### maximize button
Rightmost (green) of three window controls at left of title bar. Click to go full screen; Option-click to *maximize* the window.

See also [maximize](#maximize).

### minimize (v.), minimized (adj.)
OK for windows in the Dock.

> To put a document in the Dock, click the minimize button.
> Document windows in the Dock are minimized.

### minimize button
Middle (yellow) of three window controls at left of title bar. Click to put a window in the Dock (*minimize* the window).

### More button
Use for button with an ellipsis (with or without a circle) that opens a menu of more options.

> To show completed reminders, tap the More button, and then tap Show Completed.

If you can't use an inline graphic for the More button, use the ellipsis.circle SF Symbols glyph, or find the midline horizontal ellipsis character in Character Viewer.

See also [Action pop-up menu](#action-pop-up-menu); [Character Viewer](#character-viewer).

### pane
In user materials, use *pane* (not *panel*) for an area in a window or dialog that changes when a button is clicked: *the AutoFill pane of Safari settings*.

Often you can avoid *pane* by describing how to reach an onscreen item: *Open Safari settings, and then click AutoFill*. Referring to a pane within a pane is OK.

See also [tab](#tab).

### panel
Don't use in user materials; use *dialog*, *window*, or *pane*.

In developer materials, use *panel* in most contexts, because *Panel* appears in programming symbol names (for example, `SFChooseIdentityPanel` and `SFCertificatePanel`). When the developer sees the panel as a user does (such as in instructions for using developer apps), use the matching user term.

See also [dialog](#dialog); [pane](#pane); [window](#window).

### pointer
Usually call the arrow pointer simply *the pointer*. Don't use *cursor*.

The Finder and some apps show different pointers depending on user activity (for example, the *crosshair pointer* or the *I-beam pointer*).

Use a specific pointer name only to distinguish pointer types (for example, in tasks where the pointer changes shape).

> Drag the crosshair pointer over the area you want to capture.

See also [cursor](#cursor); [insertion point](#insertion-point).

### popover
Don't use in user materials; describe what user must select or do. If needed, use *in the list that appears* or similar wording. Don't call it a *dialog* or *window*.

> Correct: Tap Print.
> Incorrect: Tap Print in the popover.
> Correct: Scroll to the bottom of the list of messages and tap Load More Messages.
> Incorrect: Scroll to the bottom of the popover and tap Load More Messages.

### pop-up (n., adj.)
For ads or unsolicited notices opening from a browser window, prefer *pop-up* as an adjective (*pop-up ads*, *pop-up window*). In headings and other tight spaces, or content using the term repeatedly, *pop-up* is OK as short form of the noun.

> You can prevent websites from displaying pop-ups.

Don't use *pop-up* for a pop-up menu; always use *pop-up menu*.

### pop-up menu
See [menus](#menus).

### port
Use for a location passing data in and out of a computer or device. Don't use *connector* for a port. See also [connector](#connector); [jack](#jack); [slot](#slot); [socket](#socket).

### progress indicator
Generic term for an onscreen element showing users a process is underway.

In developer materials, use *asynchronous progress indicator* for the spinning gear, *determinate progress bar* for the bar whose fill moves left to right, and *indeterminate progress bar* for the spinning striped cylinder.

If you must mention a progress indicator in user materials, use the generic term and describe it.

> A progress indicator (looks like a spinning gear) appears.
> A progress indicator (a moving bar) shows the status of the download.
> A progress indicator (a spinning striped cylinder) lets you know that a process is taking place.

See also [asynchronous progress indicator](#asynchronous-progress-indicator); [determinate progress bar](#determinate-progress-bar); [indeterminate progress bar](#indeterminate-progress-bar); [spinning wait cursor](#spinning-wait-cursor).

### asynchronous progress indicator
In developer materials, progress indicator that looks like a spinning gear. In user materials, use *progress indicator* and describe its look.

> Developer materials: Don't use the asynchronous progress indicator for processes that start out indeterminate but could become determinate.
> User materials: A progress indicator (looks like a spinning gear) appears.

See also [indeterminate progress bar](#indeterminate-progress-bar).

### determinate progress bar
In developer materials, progress bar that fills left to right. In user materials, use *progress indicator* and describe its look.

> Developer materials: Use a determinate progress bar when you can tell the user how much of a process has been completed.
> User materials: A progress indicator (a moving bar) shows the status of the download.

### indeterminate progress bar
In developer materials, progress bar with a spinning striped cylinder. In user materials, use *progress indicator* and describe its look.

> Developer materials: Use an indeterminate progress bar when the duration of a process can't be determined.
> User materials: A progress indicator (a spinning striped cylinder) lets you know that a process is taking place.

See also [asynchronous progress indicator](#asynchronous-progress-indicator).

### radio button
Labeled circular button presenting mutually exclusive options.

Users *select an option*. Avoid the term *radio button*, except in developer materials. Refer to the option's label, or to the label introducing a group of radio buttons.

> Select "Automatically based on mouse or trackpad."
> In the "Show scroll bars" area, select "When scrolling."
> To change the location of the Dock, select an option next to "Position on screen."

See also [checkbox](#checkbox).

### resize control

> Click the right arrow to view more episodes.

Don't use when you mean *Forward button*.

### selection rectangle
Rectangular outline shown when users drag across onscreen items to select them. Often, say *drag to select* instead.

### share sheet
Note capitalization. In most user materials, avoid *share sheet*; describe what user must select or do.

> Correct: Tap [the share icon], and then tap Messages.
> Incorrect: Tap [the share icon], and then tap Messages in the share sheet.

*share sheet* is OK in developer materials and in user materials about changing share sheet options.

See also [action sheet](#action-sheet); [sheet](#sheet).

### sheet
macOS: dialog attached to a specific window (usually a document) that blocks further interaction with that window until dismissed.

In user materials, call a sheet a *dialog* (*sheet* is used mainly in developer materials).

> User materials: Use the Print dialog to choose a printer and select print options.
> Developer materials: When the user responds to a sheet and another sheet for that document opens, the first sheet must close before the second one opens.

See also [action sheet](#action-sheet); [share sheet](#share-sheet).

See [menus](#menus).

### side button
Use for button on the right side of iPhone or next to the Digital Crown on Apple Watch.

> Press the side button on Apple Watch to open Control Center.
> To turn off iPhone, press and hold the side button and either volume button.

Use *press* for one press of the side button; use *double-click* or *triple-click* for more than one.

### sidebar
Use for a column in a Finder or app window showing items such as available disks and other devices, mailboxes, playlists, or favorite items.

### slider
Object users drag to set a value on a continuum (a range of values). Whole control is the *slider control*.

Depending on context, users may *click*, *tap*, or *drag* a slider. Avoid the verb *slide* with *slider*.

> Correct: Tap the slider, and then swipe up or down with one finger.
> Correct: To adjust the magnification, drag the Zoom Level slider.
> Incorrect: Slide the slider, and then swipe up or down with one finger.

See also [slide (v.)](voice-and-tone.md#slide-v).

### slot
Long, thin socket on the main logic board where peripheral cards are inserted. Don't use *connector* for a slot. Lowercase *slot* when followed by a number (*slot 1*, *slot 2*). See also [connector](#connector); [jack](#jack); [port](#port); [socket](#socket).

### socket
Use for a receptacle with holes that receives a plug or another connector. Don't use *female connector*. See also [connector](#connector); [jack](#jack); [port](#port); [slot](#slot).

### spinning wait cursor
In developer materials, the colored pinwheel cursor. In user materials, use *wait cursor*.

> Developer materials: Try to avoid situations in your app that cause the window server to display the spinning wait cursor.
> User materials: You might see a wait cursor (looks like a colored pinwheel) while the app is opening.

### stepper
In developer materials, use for a control with up and down (or left and right) arrows that increases or decreases a value. Don't use in user materials unless you must refer to the control itself; use *up arrow*, *down arrow*, *right arrow*, *left arrow*, or *arrows*, as appropriate. For example, *Click one of the arrows to increase or decrease the volume*.

### submenus
Use when describing hierarchical menus. Highlighting a menu item with a submenu indicator (looks like a right arrow) opens a submenu.

To describe choosing an item from a submenu, use one of these styles:

> Choose View > Sort By > Name.
> Choose View > Sort By, and then choose an item from the submenu.

See also [choose](voice-and-tone.md#choose); [menus](#menus).

### switch (n.)
Interface element offering two mutually exclusive choices, usually on and off (use lowercase for *on* and *off*, even if control options are uppercase). Often no need to mention the switch itself; describe the user's action to operate it.

> Tap to turn on Location Services.
> Tap Airplane Mode on or off.

If you must refer to the switch (to give its location, for example), avoid the verbs *switch* or *slide* with it; use *tap* or *click* instead.

> Correct: To turn Airplane Mode on or off, tap the switch in the upper-right corner.
> Incorrect: To turn Airplane Mode on or off, slide the switch in the upper-right corner.

See also [switch (v.)](word-choice-and-confusables.md#switch-v).

### tab
Use *tab* for two different UI elements:

- Separate view of content a user can open in an app (such as Safari).

Use *tab* for the entire view: both the part visible in the tab bar and what users see on clicking or tapping it.

> You can open a webpage in a new tab.
> Drag a tab out of the window to make it a separate window.

- Control at the bottom of the screen for quickly switching between sections of an iOS app.

Use *tab* for the entire view: both the control at the bottom of the screen and what users see on tapping it.

> The screenshot is added to the Photos tab in Photos.

In developer materials, use *tab bar* for the entire group of tabs.

In user materials, don't use *tab* for a changeable content area built into a macOS window; use *pane*. Use *button* for the control users click to see the pane (or refer to the control by its label).

In developer materials, use *tab* for the control users click; use *pane* or *view* for the view users see on clicking.

See also [button](#button); [pane](#pane).

### Touch Bar
Narrow Multi-Touch surface above the keyboard on some Mac laptop computers. Don't shorten to *the Bar*. Generic names for its items: *controls*, *items*, or *tools*. Items are *in* (not *on*) the Touch Bar. Describe interaction with standard Multi-Touch gestures (including *tap*, *swipe*, *drag*, and *touch and hold*). Users don't *press* the Touch Bar.

> You can use the controls in the Touch Bar to play and pause a movie.
> Tap Edit in the Touch Bar.
> Drag the scrubber in the Touch Bar.

Can also say *use the Touch Bar* to point users to a Touch Bar method for a task.

See also [Control Strip](#control-strip).

### Touch surface
Touch-sensitive upper half of the Siri Remote. You *press* the Touch surface, rather than *tap* or *click*.

> Press left or right on the Touch surface to skip backward or forward.
> Swipe up on the Touch surface to reveal more information.
> To access contextual (shortcut) menus, press and hold the Touch surface.

See also [Apple TV Remote](apple-products.md#apple-tv-remote); [Siri Remote](apple-products.md#siri-remote).

### up arrow
Use for small arrow users click to increase a value in a stepper.

> Click the up arrow to increase the text indent.

See also [stepper](#stepper); [Up Arrow key](#up-arrow-key).

### Up Arrow key
See [arrow keys](#arrow-keys).

### value slider
Slider that shows the parameter's numeric value in the control. Drag up or right to increase the value; drag down or left to decrease it.

### View control
Four-button unit for changing Finder window views. Holds the Icon View button, the List View button, the Column View button, and the Gallery View button. See also [Column View button](#column-view-button); [Gallery View button](#gallery-view-button); [Icon View button](#icon-view-button); [List View button](#list-view-button).

### viewer window
In the Mail app in macOS, main window where mailboxes and messages appear. On first occurrence, call it *the Mail viewer window*; later, *the viewer window*.

### window
In user materials, use *window* for interface elements below.

- *macOS and visionOS:* Use *window* for main app windows, document windows, and windows with controls or options affecting the active document or selection, such as the Fonts window.

> All macOS windows have a functional close button in the title bar.

- *iPadOS:* Use *window* for app windows visible at the same time (for example, when someone multitasks using Split View or Slide Over).

> You can open two windows from the same app in Split View.

Can also use *window* for a Picture in Picture window. See also [Picture in Picture (n., adj.), picture-in-picture (adj.)](#picture-in-picture-n-adj-picture-in-picture-adj).

Don't use *window* for a popover. See also [popover](#popover).

Except for the Picture in Picture window, don't use *window* for interface elements in iOS. Instead of naming an element, usually describe what user must select or do. If needed, use alternative words such as *list*.

> Correct: To see more table styles, scroll left or right.
> Incorrect: To see more table styles, scroll left or right in the Tables window.

See also [dialog](#dialog); [pane](#pane); [sheet](#sheet); [tab](#tab).

### window bar
In visionOS, horizontal bar at the bottom of a window that lets you move the window.

### window controls
Standard window controls: close button, minimize button, and maximize button.

### window titles
When naming a window, use the exact words in its title bar (*the Mail window*, *the About This Mac window*). Lowercase *window* (unless part of the window title and capitalized).

### Character Viewer
Systemwide macOS window for selecting and inserting emoji, symbols, and other special characters in text. To open it, choose Edit > Emoji & Symbols in most macOS apps.

### Picture in Picture (n., adj.), picture-in-picture (adj.)
Use *Picture in Picture* for the feature that lets users view a movie in one part of the screen while doing other tasks.

> To stop playing a movie using Picture in Picture, click [the PiP icon].
> You can drag the Picture in Picture window to any corner of the screen.

For general references to playing a smaller video within a larger area, use *picture-in-picture*.

> Select the clip you want to use as a picture-in-picture clip.

In documents using *Picture in Picture* or *picture-in-picture* often, you can use abbreviation *PiP* after first occurrence.
