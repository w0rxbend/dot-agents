# Capitalization

Capitalization rules: when to capitalize, headings, title case, proper names, sentence-style vs title-style.

## Entries

### capitalization
Apple commonly uses two capitalization styles:

- *Sentence-style capitalization:* This line provides an example of sentence-style capitalization.
- *Title-style capitalization:* This Line Provides an Example of Title-Style Capitalization.

Except for user interface text, choosing sentence-style or title-style capitalization is department style.

Capitalize onscreen element names exactly as they appear onscreen. If an element uses all capitals or all lowercase, use title-style capitalization when naming it in documentation.

Don't capitalize *chapter* or *appendix*, except in cross-references to actual titles.

> See Chapter 2, "Units of Measure."
> See the appendix for specifications.
> See Appendix B for a list of specifications.

In title-style capitalization, capitalize:

- First and last word, regardless of part of speech
- Nouns, pronouns, verbs, adjectives, and adverbs of any length (for example, *It, This, You, Your, My, Is, Are,* and *Be*), unless listed as exception below

> Skip This Backup
> Apple News Is Offline
> Passwords Are Locked

- Conjunctions of any length (for example, *If*), except coordinating conjunctions

> What to Do If Your iPhone Is Lost

- Prepositions of five letters or more (for example, *About, Between, Through*)
- Prepositions of any length in a phrasal verb (such as *Start Up, Turn On,* or *Log In*) or used as another part of speech (adverb, adjective, noun, or verb)

> Start Up the Computer
> Turn On Apple Watch
> Log In to the Server

- Second word in a hyphenated compound (except *Built-in* and *Plug-in*)

> High-Level Events
> 64-Bit Addressing

In title-style capitalization, don't capitalize:

- Articles (*a, an, the*), unless first word or after a colon
- Coordinating conjunctions (*and, but, or, nor, for, yet,* and *so*)
- Word *to* in infinitives (*How to Start Your Computer*)
- Word *as*, regardless of part of speech (*Export a Document as a PDF*)
- Words that always start lowercase, such as *iPad* and *macOS*
- Prepositions of four letters or fewer (*at, by, for, from, in, into, of, off, on, onto, out, over, to, up,* and *with*)

> Don't Speak in Silent Mode
> Collaborate with Others
> Restore iPhone from a Backup

*Exception:* Capitalize prepositions of any length in a phrasal verb, as in the "capitalize" list above.

See also [abbreviations and acronyms](abbreviations-and-acronyms.md#abbreviations-and-acronyms).

### chapter
Don't capitalize *chapter*, except in cross-references to actual titles (exception to *The Chicago Manual of Style*).

> in Chapter 5, "Expanding Your Computer"
> in Chapters 4 and 5
> in the next chapter

See also [capitalization](#capitalization).

### command names
Use title-style capitalization for command names; don't capitalize *command*.

> the Find command
> the Make Alias command

- *Commands used as ordinary verbs:* Don't capitalize a command name used as a normal English verb.

> Correct: Cut and paste the selected text.
> Incorrect: Cut and Paste the selected text.

- *Ellipsis:* Some menu commands use an ellipsis to show further action is required. Don't include the ellipsis when naming the command in text or text headings.

> Correct: Choose File > Print, and then enter the number of copies.
> Incorrect: Choose File > Print…, and then enter the number of copies.
