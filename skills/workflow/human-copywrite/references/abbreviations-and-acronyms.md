# Abbreviations and Acronyms

Apple Style Guide entry on abbreviations and acronyms, plus technical/industry acronym definitions. For spelling out any entry below, follow [abbreviations and acronyms](#abbreviations-and-acronyms) unless the entry says otherwise.

## Entries

### abbreviations and acronyms
Acronym: pronounceable word formed from initial letter or letters of major parts of a compound term. Abbreviation: usually formed same way but not pronounced as a word. Abbreviations often lowercase or mixed lowercase and uppercase. Acronyms almost always all caps, regardless of capitalization style of spelled-out form.

> Abbreviation: mph—for *miles per hour*; MB/s—for *megabytes per second*
> Acronym: ROM—for *read-only memory*

- *When to spell out:* If audience might not know an abbreviation or acronym, spell out first occurrence on a page or in a section. In user materials, spell out term when introducing it.
- *How to spell out:* Generally put spelled-out version first, abbreviation or acronym in parentheses.

> internet service provider (ISP)

If abbreviation or acronym is much more familiar than spelled-out version, two options. Put abbreviation or acronym first, spelled-out version in parentheses. Or say abbreviation is "short for" spelled-out version, with spelled-out version in italics.

> You can share your personal URL (Uniform Resource Locator).
> An internet address is sometimes called a *URL*, short for *Uniform Resource Locator*.

- *File types:* All caps for file type abbreviations.

> a JPEG file, an AIFF file, the MP3 file

Filename extensions, which indicate file type, use lowercase.

> .jpg, .aif, .mp3, .iba

See also *filename extensions*; [file types](#file-types).

- *Pronunciation:* If reader might not know how to pronounce acronym, give pronunciation key.

> WYSIWYG (pronounced "WIZ-zee-wig")

See also *pronunciation*.

- *Articles:* Choose *a* or *an* by pronunciation of abbreviation or acronym.

> a SAN, a USB port, an FAQ, an LCD screen

- *Punctuation:* No periods, except in abbreviations for nonmetric units of measure and in *a.m.*, *p.m.*, and *U.S.* (see [U.S.](#us) for exception).
- *Plural:* No apostrophe before *s* in plural of an abbreviation.

> CDs, ICs, ISPs

- *Latin:* Avoid Latin abbreviations.

> Correct: *for example*, *and others*, *and so on*, and *that is*, or equivalent phrases
> Incorrect: *e.g.* (for example), *et al.* (and others), *etc.* (and so on), *i.e.* (that is)

- *Units of measure:* See [Units of measure](units-of-measure.md) for detailed usage.
- *Product names:* Don't abbreviate any Apple product or service name, whether or not trademarked or service-marked.

### AAC
Abbreviation for *Advanced Audio Coding*, industry-standard audio compression format.

### AC
Abbreviation for *alternating current*.

### AFP
Abbreviation for *Apple Filing Protocol*.

### ANSI
Acronym for *American National Standards Institute*.

### APFS
Abbreviation for *Apple File System*, default file system for formatting Apple devices and external storage devices.

### API
Abbreviation for *application programming interface* (not *application program interface*). Plural: *APIs*.

### APN
Abbreviation for *Access Point Name*.

### APNs
Abbreviation for *Apple Push Notification service*, Apple's service that lets developers send push notifications. See also [push notification](apple-features-software.md#push-notification).

### ASCII
Acronym for *American Standard Code for Information Interchange*.

### ASIC
Acronym for *application-specific integrated circuit*. Note hyphen in spelled-out version.

### AVCHD
Abbreviation for *Advanced Video Coding High Definition*, high-definition digital video format for recording and playback.

### bit/s
Abbreviation for *bits per second*.

### bps
Don't use as abbreviation for *bits per second*. Use *bit/s*.

### CD
Abbreviation for *compact disc*. Use *disc*, not *disk*, for CD media.

### CLUT
Acronym for *color lookup table*.

### CPU
Abbreviation for *central processing unit*. Avoid in user materials; use *processor* for the chip and *computer* or *system* for the computer itself. See also *computer*; [processor](apple-features-software.md#processor); *system*.

### CR
Abbreviation for *carriage return*. Use only when referring specifically to ASCII character $0D or its equivalent. Explain *carriage return* if audience includes first-time computer users.

Use *return character* when writing about, for example, searches for return characters. Use *Return key* for the key users press.

### Ctrl
Abbreviation for *Control*. Use abbreviation only when space constraints don't allow full term (as in table column headings). Otherwise use *Control*, as in *Control key* or *Control-S*. Don't use *CTRL*.

### DAC
Acronym for *digital-to-analog converter*. Note hyphenation in spelled-out version.

### DIMM
Acronym for *dual inline memory module*.

### dpi
Abbreviation for *dots per inch* (n.) and *dot-per-inch* (adj.).

> The printer provides a resolution of 600 dots per inch (dpi); it can be upgraded to 1200 dpi.
> The printer provides a 600-dot-per-inch (dpi) resolution; some printers offer 1200 dpi resolution.

### DRAM
Acronym for *dynamic random-access memory*. Pronounced "DEE-ram."

### DRM
Abbreviation for *digital rights management*.

### DV
Industry-standard video format. Generally use *DV* for the format or for products using it. Don't use *DV* for the medium *digital video*. Related terms: *DV format*, *DV standard*, *DV camera*, *DV camcorder*.

### DVD
Optical disc for high-capacity storage. Use *disc*, not *disk*, for DVD media.

### DVI
Abbreviation for *Digital Visual Interface*, not *Digital Video Interface*.

### DVR
Abbreviation for *digital video recorder*. Use for a device, such as a portable media player or set-top box, that records digital video to file-based media such as a hard disk or optical disc. Don't use *DVR* when you mean *camcorder*. See also *camcorder*.

### EMI
Abbreviation for *electromagnetic interference*.

### EU
No periods. OK to abbreviate or spell out *European Union* as a noun. Use abbreviation for adjective form.

### FAQ
Abbreviation for *frequently asked questions*. *FAQ* is singular; use article *an*. Use *FAQs* for more than one set of frequently asked questions. Use title-style capitalization if full term precedes a noun: *the Frequently Asked Questions document*.

### fps
Abbreviation for *frames per second*. Put a space between number and *fps*: *24 fps*.

### FTP
Abbreviation for *File Transfer Protocol*. Avoid as a verb; use *transfer files* instead. UNIX command `ftp` is all lowercase. In *anonymous FTP*, the *a* is lowercase.

> Correct: You can use FTP software to transfer files from a remote computer to your computer.
> Correct: You use the `ftp` command to transfer files from a remote computer to your computer.
> Incorrect: You can FTP files from a remote computer to your computer.

### GIF
Acronym for *Graphics Interchange Format*, bitmapped graphics file format with data compression. See also *file format*.

### GPU
Abbreviation for *graphics processing unit*.

### GUI
Acronym for *graphical user interface*. Don't use. Use *interface* (user materials) or *UI* (developer materials).

### H.264
Video compression standard (or video codec). Also known as *MPEG-4 Part 10* and *AVC* (or *Advanced Video Coding*).

### HD (n., adj.)
Abbreviation for *high definition* (n.) and *high-definition* (adj.).

### HDMI
Abbreviation for *High-Definition Multimedia Interface*. Related terms: *HDMI port*, *HDMI input*, *HDMI output*, *HDMI cable*, *HDMI to HDMI cable*, and *HDMI to DVI cable*.

### HDR (n., adj.)
Abbreviation for *high dynamic range* (n.) and *high-dynamic-range* (adj.). Video or still-image format allowing additional brightness levels per color component.

### HDV
Format for recording and playback of high-definition video on standard DV cassette tapes, using a form of MPEG-2 compression. Don't use *HDV* for high-definition video in general.

### HFS Plus
Not *HFS+*. Technical name for a file system used to format a disk for macOS. (*HFS* stands for *hierarchical file system*.) Avoid in user materials; use *Mac OS Extended format* instead.

### HFS Plus (Journaled)
Not *HFS+ (Journaled)*. Avoid in user materials; use *Mac OS Extended (Journaled) format* instead.

### HTML
Abbreviation for *Hypertext Markup Language*. Lowercase when part of a URL.

### HTTP
Abbreviation for *Hypertext Transfer Protocol*. Lowercase when part of a URL.

### HUD
Acronym for *heads-up display*, a window for making adjustments and selecting options in some apps. Precede *HUD* with *a*, not *an*. Avoid unless term appears in the user interface.

### IEEE
Abbreviation for *Institute of Electrical and Electronics Engineers*.

### IM
Abbreviation for *instant message*. Don't use; use *message*.

### IMAP
Acronym for *Internet Message Access Protocol*. Pronounced "eye-map."

### IP
Abbreviation for *Internet Protocol*.

### IrDA
Abbreviation for *Infrared Data Association*.

### ISDN
Abbreviation for *Integrated Services Digital Network*.

### ISP
Abbreviation for *internet service provider*; not *ISP provider*.

### I/O
Abbreviation for *input/output*.

### IPsec
Abbreviation for *Internet Protocol Security*.

### JPEG
Acronym for *Joint Photographic Experts Group* (pronounced "JAY-peg"). *JPEG* usually means the image compression standard this group developed for color and grayscale images. No need to spell out *JPEG* on first occurrence.

### LAN
Acronym for *local area network*.

### LCD
Abbreviation for *liquid crystal display*.

### LCI
Abbreviation for *liquid contact indicator*. Spell out on first occurrence. In later references, *LCI* or *the indicator* is OK.

### LED
Don't use in user materials unless there's a specific reason (to distinguish from LCD, for example). Use *light* or *indicator light*.

### MIDI
Acronym for *Musical Instrument Digital Interface*.

### MIME
Acronym for *Multipurpose Internet Mail Extension*, commonly used to distinguish an email format from plain text format. No need to spell out on first occurrence. Use as an adjective (*a MIME file*, *MIME format*).

### MIPS
Acronym for *million instructions per second*. Don't drop the *s* for a single unit: *1 MIPS*, not *1 MIP*.

### MPEG
Acronym for *Moving Picture Experts Group*, a working group of the International Standards Organization (ISO). Pronounced "em-peg." No need to spell out on first occurrence.

### MP3
Short for *MPEG Audio Layer 3*, an audio compression technology. Plural: *MP3s*. Don't use *MP3* for audio files in general; some files use AAC or other formats.

### PAL
Acronym for *Phase Alternating Line*, a European color video standard.

### PDF
Abbreviation for *Portable Document Format*. No need to spell out on first occurrence. Use to refer to a PDF file.

### PIN
Acronym for *personal identification number*. For iOS or iPadOS devices, use only for the PIN that unlocks a SIM card. See also [code, passcode](word-choice-and-confusables.md#code-passcode).

### POP
Acronym for *point of presence* (access point to the internet) and *Post Office Protocol*. As acronym for *Post Office Protocol*, *POP* must modify a noun (as in *POP server* or *POP ID*).

### PRAM
Acronym for *parameter random-access memory*. Pronounced "PEA-ram."

### RAID
Acronym for *Redundant Array of Independent Disks*, a storage method that distributes data among two or more hard disk drives to improve performance and reliability. Storage methods are called *levels*: *RAID level 0*, *RAID level 1*, *RAID level 0+1*, and so on. OK to shorten to *RAID 0*, *RAID 1*, *RAID 0+1*, and so on.

### RAM
Acronym for *random-access memory*.

### RAW
Image file format. Use all caps even though *RAW* is not an acronym. Don't use *RAW* alone; use *RAW file*, *RAW image*, *RAW setting*, and so on.

### RFI
Abbreviation for *radio-frequency interference*. Note hyphenation of spelled-out version.

### ROM
Acronym for *read-only memory*.

### RSS
Abbreviation for *Really Simple Syndication*. Format for displaying latest changes to websites and blogs. Users access these RSS feeds with an RSS reader.

### RTF
Abbreviation for *Rich Text Format*.

### SAN
Acronym for *storage area network*. Precede with *a*, not *an*.

### SD
Abbreviation for *standard definition* (n.) and *standard-definition* (adj.).

### SDH
Short for *subtitles for the deaf and hard of hearing*. Define on first mention.

> Subtitles for the deaf and hard of hearing (SDH) differ from closed captions in several ways.

Use *SDH* for the technology.

> You'll find SDH on more media types than closed captioning.

Use *SDH subtitles* for the titles themselves.

### SDK
Abbreviation for *software development kit*.

### SDR (n., adj.)
Abbreviation for *standard dynamic range* (n.) and *standard-dynamic-range* (adj.). Legacy video or still-image format with limited brightness levels per color component.

### SDRAM
Abbreviation for *synchronous dynamic random-access memory*.

### SIM
Acronym for *Subscriber Identity Module*, a smart card holding subscriber information and settings. Precede with *a*, not *an*. OK to use *SIM* or *SIM card*. SIM formats include *micro-SIM* and *nano-SIM*. Related terms: *Apple SIM*, *embedded Apple SIM*, *Dual SIM*, and *eSIM*.

### SIMM
Acronym for *single inline memory module*. No hyphen in spelled-out version.

### SMTP
Abbreviation for *Simple Mail Transfer Protocol*.

### SO-DIMM
Acronym for *small outline dual inline memory module*. Note hyphenation of the acronym.

### S/PDIF
Acronym for *Sony/Philips Digital Interface Format*. Don't use *S/P-DIF*. Pronounced "spid-iff," so precede with *a*, not *an*.

### SSD
Abbreviation for *solid-state drive*. Precede with *an*, not *a*. OK to use *SSD* alone or in terms such as *SSD storage*; don't use *SSD drive*.

### TCP/IP
Abbreviation for *Transmission Control Protocol/Internet Protocol*.

### UDF
Abbreviation for *Universal Disk Format*.

### UFS
Abbreviation for *UNIX File System*, a file format available in Disk Utility, used mainly by UNIX and UNIX-based operating systems. No need to spell out on first occurrence.

### UI
Abbreviation for *user interface*. OK in developer materials. In user materials, use *interface*.

### UK
No periods. OK to abbreviate or spell out *United Kingdom* as a noun. Use abbreviation for adjective form.

### UNIX
All caps; no spelled-out version.

### URL
Abbreviation for *Uniform Resource Locator*, another term for an internet address. *URL* is pronounced "you-are-ell"; precede with *a*, not *an*. In most user materials, use *internet address* or *web address*, not *URL*. See also *internet addresses*.

### U.S.
Use periods except when abbreviation appears near other country or region name abbreviations that don't use periods. Use abbreviation as adjective only; as a noun, spell out *United States* (except in trademark notices). For country name in a U.S.-based Apple address, use *USA* (no periods). See also [America, American](#america-american).

### USB
Abbreviation for *Universal Serial Bus*. Avoid as a noun.

### USB connector types
Several types of USB connectors (and corresponding ports):

- *USB Type-A:* On first mention, describe connector's look (*rectangular*). OK to shorten to *USB-A connector* (or *USB-A port*).
- *USB Type-B:* On first mention, describe connector's look (*square*). OK to shorten to *USB-B connector* (or *USB-B port*).
- *USB Type-C:* Tiny USB connector supporting USB 3.1 and USB power delivery. OK to shorten to *USB-C connector* (or *USB-C port*).

### VPN
Abbreviation for *virtual private network* or *virtual private networking*.

### VRAM
Acronym for *video random-access memory*. Pronounced "VEE-ram."

### WAN
Acronym for *wide area network*. Note no hyphen in spelled-out version.

### WWDC
Abbreviation for *Worldwide Developers Conference*.

### WWW
Don't use as abbreviation for *World Wide Web*. Use *web* instead.

### file types
Abbreviations in all caps; filename extensions in lowercase. In most cases, no need to spell out on first occurrence. Use for a specific kind of file, such as a JPEG file or a PDF file. Don't use *file format* (a file's structure and method of storing data) when you mean *file type*.

> Correct: PNG is a file type popular for web images.
> Incorrect: PNG is a file format popular for web images.

When possible, use just *file*.

> The photo is exported as a JPEG file.
> For better playback performance, Final Cut Pro transcodes all MP3 audio files to MOV audio files.

Abbreviations and extensions for some common file types:

| Abbreviation | Extension |
|---|---|
| AIFF | .aif |
| CAF | .caf |
| DMG | .dmg |
| GIF | .gif |
| JPEG | .jpg |
| MP3 | .mp3 |
| PDF | .pdf |
| RTF | .rtf |
| TIFF | .tif |
| WAV, WAVE | .wav |

See also *file format*; *filename extensions*.

### America, American
Refers to both North and South America. Don't use when you mean *United States*. See also [U.S.](#us).
