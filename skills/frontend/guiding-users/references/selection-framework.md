# Onboarding Component Selection Framework

Criteria for picking onboarding mechanism by user state, content type and interaction requirements.

## Quick Reference Matrix

| User State | Content Type | Interaction | Recommended Mechanism |
|------------|--------------|-------------|----------------------|
| First-time | Core features | Guided | Product Tour |
| Existing | New feature | Announcement | Feature Spotlight |
| Learning | Complex task | Practice | Interactive Tutorial |
| Setup | Multi-step | Progressive | Checklist |
| Confused | Context help | On-demand | Tooltip/Hint |
| Research | Documentation | Self-service | Help Panel |
