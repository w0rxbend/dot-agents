# Select commands by evidence

Use installed compiler's help and [official compiler manual](https://crystal-lang.org/reference/1.19/man/crystal/index.html); match documentation version to checkout/toolchain. Focused workflow: `crystal tool format --check src spec`, `crystal spec spec/path_spec.cr`, then full `crystal spec` when behavior dependencies warrant. Confirm flags on historical compilers. `crystal build src/main.cr -o <scratch-output>` builds executable; `crystal run` compiles and executes. Specs also compile and execute. Compiler/macro-time subprocesses can still run during build, so inspect source/manifest hooks when choosing isolated checks.

Read [Shards manual](https://crystal-lang.org/reference/1.19/man/shards/index.html) for selected version. `shards install` resolves/downloads into `lib` and creates or uses `shard.lock`; `shards update` intentionally refreshes resolution. Do not replace install with update as generic repair. Keep application dependency locks reviewable; for libraries, follow existing repository policy. Build declared executable targets with `shards build <target>` when supported. Playground target is `starter`, not its repository name. Its manifest currently has no dependencies, so source edits do not automatically need dependency fetching.

See [official testing guide](https://crystal-lang.org/reference/1.19/guides/testing.html) for `Spec` and `*_spec.cr`. Assert behavior at real requireable boundary: exact streamed bytes, empty/non-ASCII input where supported, failures and relevant ownership cleanup. Never replace failed expected value with implementation output solely to pass. If subprocess or socket participates, use existing fake/temporary resource seam before live service check. Spec dry-run is not execution evidence.

Run benchmarks only for performance request, with equivalent inputs/output contracts, compiler optimization, architecture and buffer-reset conditions recorded. Report throughput/allocation separately from formatting/build/spec status. Avoid generalizing one IO microbenchmark to all serializers or all supported compilers.
