# Browser-source rendering and lifecycle

Portfolio evidence: [overlay socket lifecycle](https://github.com/w0rxbend/twitch-vizer/blob/7fa2861b322a75f9ad5fb395e616645d7f063ab5/frontend/src/shared/socket.ts), [wire normalization](https://github.com/w0rxbend/twitch-vizer/blob/7fa2861b322a75f9ad5fb395e616645d7f063ab5/frontend/src/shared/events.ts), [CreationEngine](https://github.com/w0rxbend/obs-effects/blob/ad8d6fd8767c7bd90a9746b076c80797cf53c46d/src/engine/engine.ts) and [CameraScreen](https://github.com/w0rxbend/obs-effects/blob/ad8d6fd8767c7bd90a9746b076c80797cf53c46d/src/app/screens/CameraScreen.ts). obs-effects is archived: existing-code context, not revival target. General Pixi API questions: version-matching [PixiJS docs](https://pixijs.com/8.x/guides/components/application).

Keep transparent canvas and browser-source dimensions. Pixi 8 initialization is async: do not use renderer/canvas or attach scene assets before `init` and required bundle load complete. Derive resolution from existing helper and renderer limits; blindly raising device-pixel ratio raises texture and render-target cost. Animate by elapsed time, not presumed fixed refresh rate.

Treat as distinct lifecycle states: initialization, active display, hidden/paused, reconnection, scene replacement, destruction. Socket ownership guards must cover late open, message, close and retry callbacks. Reviewed socket guards old close but not every callback; stale open/message callbacks can still change status or inject old events after replacement. Teardown: cancel retry timers, detach listeners/ticker callbacks, close sockets, dispose scene-owned textures/filters/media, abort pending work. Shared asset-cache textures need explicit ownership; destroying one scene must not break another. Pause/resume follows OBS source behavior and audio expectations.

Normalize events in shared boundary: tolerate camelCase/snake_case avatar and animated/static emote aliases there, not in each card renderer. Supply fallback assets/text for malformed or unavailable external media. Bound cards/particles, GPU caches and animated-image decoders so long-running source does not grow per user/message.

Use HTTPS→WSS URL derivation and existing deployment proxy/path; never hard-code development port into production scene. Keep `?debug=1` gating for synthetic key-triggered events. Validate resize, asset readiness, transparency, disconnect/reconnect, hidden/resumed state, repeated scene teardown. Record browser/WebGL checks separately from real OBS embedded-browser checks; plain Chromium test does not prove identical OBS CEF behavior.
