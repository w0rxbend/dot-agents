# Context-sensitive findings

Examples from 55-issue review of `worxbend_obs-websocket-client` at revision `b994a9c0f8d0cdb15f28618dfb18e4d7da235f76`. Counts and project policy are historical examples, not global requirements.

- **GitHub Actions S7630:** direct expression interpolation in shell is fragile even when earlier required job validates that exact input. Verify `needs`, conditions, failure behavior before describing exploitability. Also prefer environment data and quoted shell arguments at sink.
- **S2068 test credentials:** check whether values authenticate to anything real. Synthetic passwords, invalid credential-bearing URIs, `password=<set>`, `<unset>`, HOCON null values can intentionally test rejection/redaction. Do not delete or randomize those cases merely to silence scanner. Recommend narrow false-positive disposition with evidence; do not apply it remotely without authorization.
- **S8707 CLI paths:** arbitrary output path can be intentional CLI contract. Establish caller and authorized destination before imposing confinement. Build-only writer with Mill-managed output contract can validate under `out/`. General export command may rightly allow explicit external path. Directory creation and file writes from one tainted argument are distinct reported sinks, often one root cause. `resolve()` plus ancestry checks handle existing symlinks but are not race-proof sandbox against concurrent hostile filesystem mutation.
- **S5443 temporary paths:** inspect actual filesystem namespace. Fixed `/tmp` directory in unique disposable container with no host mounts differs from shared host path. Prefer private owned state for configuration and logs. Keep required third-party rendezvous paths like X11 sockets when isolation justifies them. Turning literal into constant is not security fix.
- **S3776 frozen benchmark:** refactoring verbatim legacy implementation can destroy experimental baseline. Keep benchmark intact, document intentional exception, improve production code separately. Never exclude whole production module merely to lower issue counts.
- **S6353 regex simplification:** Python `\w` matches Unicode by default. Mechanically replacing ASCII ranges can widen what validator or code generator accepts. Preserve flags/semantics; test non-ASCII inputs. Global `re.ASCII` can also narrow existing `\s` matches; use scoped identifier group when whitespace must stay Unicode-aware.
- **S8786 regex performance:** unanchored digit run followed by suffix can retry at every position in long near miss. Test adversarial nonmatching input, not only successful matches. Local tool input lowers exposure but does not remove unnecessary work.
